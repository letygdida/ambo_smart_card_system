HOW TO USE - MANUAL MODE
====================================================================

1. Open: http://localhost:3001/employee-attendance
2. Login as Admin/Staff
3. Click "ATTENDANCE CONTROL" tab (2nd tab)
4. Select Attendance Type (Check-In, Check-Out, etc.)
5. Ensure Control Mode is "Manual"
6. Click "OPEN ATTENDANCE" button → Status shows 🟢 OPEN
7. Employees can now scan/mark attendance
8. Click "CLOSE ATTENDANCE" button → Status shows 🔴 CLOSED
9. Employees CANNOT mark attendance when closed

====================================================================
HOW TO USE - AUTOMATIC MODE
====================================================================

1. Go to "ATTENDANCE CONTROL" tab
2. In Configuration section, select "⏰ Automatic Mode"
3. Set Start Time (e.g., 08:00)
4. Set End Time (e.g., 15:10)
5. Set Active Days (e.g., Monday,Tuesday,Wednesday,Thursday,Friday)
6. Click "Save Configuration"
7. System will automatically OPEN at start time
8. System will automatically CLOSE at end time
9. Works only on configured active days
